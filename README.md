Учебный проект простейшего веб-сервера на Python, упакованного в Docker-контейнер, с настроенным локальным CI/CD-пайплайном автоматического развёртывания.
Проект создан для отработки навыков контейнеризации и автоматизации деплоя. Поддерживает два сценария работы: локальный (через Bash-скрипт) и облачный (заготовка CI/CD пайплайна GitHub Actions в файле deploy.yaml).


* `main.py` — исходный код веб-сервера на Python, отдающий страницу "Aboba в сети!".
* `Dockerfile` — инструкция по сборке оптимизированного Docker-образа (с настройками кэширования и логирования).
* `deploy.sh` — локальный пайплайн, автоматизирующий сборку, удаление старого и запуск нового контейнера.
* `.github/workflows/deploy.yaml` — конфигурация облачного CI/CD-пайплайна для автоматизации через GitHub Actions.


1. Локальный автоматический деплой (Пайплайн)

Убедитесь, что Docker Desktop запущен. Выполните скрипт автоматизации:
```bash
./deploy.sh
```
Скрипт соберёт образ `aboba-web`, остановит старый контейнер и поднимет новый в фоновом режиме на порту `80`.

2. Мониторинг и проверка
* Посмотреть работающий контейнер: `docker ps`
* Посмотреть логи запросов в реальном времени: `docker logs -f web-container`

3. Вывод приложения наружу (в глобальный интернет)
Чтобы открыть доступ к сайту для внешних пользователей, используется туннель:
```bash
npx localtunnel --port 80
```
Вставьте ваш внешний IP (можно узнать через `curl ifconfig.me`) в поле **Tunnel Password** на открывшейся странице.

Как убрать за собой
Чтобы полностью остановить проект и освободить ресурсы:
```bash
docker stop web-container && docker rm web-container
```
